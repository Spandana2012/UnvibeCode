Save a request session using a signed cookie.

At the end of a request, Flask's default SecureCookieSessionInterface evaluates the session and may set or delete its signed session cookie on the response.

Workflow 5

Serve a Blueprint's static file to a requesting client.

A request reaching a registered Blueprint static route invokes send_static_file, which serves a file from the Blueprint static folder through send_from_directory.

What it produces

Who relies on it

Why this workflow matters

  • Returns requested file contents when available.
  • The directory-based helper confines requested paths to the configured directory and reports missing or non-regular targets as 404 according to its documented contract.

Workflow 6

Attach deferred Blueprint routes, callbacks, and commands to a Flask application.

What this workflow does

Application registration of a Blueprint records it in the application's registry, merges applicable callbacks, applies deferred setup functions, and registers nested blueprints and CLI commands.

Purpose

Make a configured Blueprint's application features available on an application.

What it produces

Blueprint, application blueprint registry, routes, and callback registries.

Who relies on it

The Flask application and its eventual request or CLI consumers.

Why this workflow matters

  • Makes blueprint-defined routes and callbacks part of the application.
  • Supports nested blueprints and configurable route prefixes, subdomains, and names.
